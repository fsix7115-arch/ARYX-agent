# ARYx AGENT

Your terminal AI agent. One command to install. Any API key.

## Quickstart (30 seconds)

```bash
git clone https://github.com/fsix7115-arch/ARYX-agent
cd ARYX-agent/aryx-agent
./install.sh
aryx
```

Paste your API key when asked. That's it — ARYx auto-detects the provider
from the key prefix, validates it with a tiny probe, and drops you straight
into the chat.

## Layout

- `aryx-agent/` — the Python project: installer, source, tests, and docs.
  Start with [`aryx-agent/README.md`](aryx-agent/README.md).
- The remaining files at this repo root are a separate experimental web
  console and are not needed to run the terminal agent.
